About

An introduction to what Formix is and the principles it's run by.

What is Formix?

Formix is a free collection of online utilities that lets you handle small but tedious tasks you often run into during development or work, directly in your web browser — no separate program to install, no sign-up required. The first tool we offer is the JSON Formatter, and we plan to keep adding tools that are genuinely useful in everyday work.

Our principles

  • Use it instantly, no sign-up — Anyone can start using it immediately — no account or login required.
  • Client-side processing — Most tools process your input entirely in the browser (JavaScript) and never send it to a server. See our Privacy Policy for details.
  • Light and fast — We aim for a simple screen that cuts unnecessary elements and focuses on the features you actually need.
  • Dark mode built in — Choose between light and dark themes, either automatically from your system settings or manually with the toggle.

Available features

  • JSON Formatter / Viewer — Validates JSON strings and displays them as an indented, syntax-highlighted tree. Supports collapsing/expanding nodes and searching keys and values.
  • XML Formatter / Viewer — Validates XML strings and displays them as an indented, syntax-highlighted tree. Supports collapsing/expanding nodes and searching tags, attributes, and text.
  • JSON ↔ XML Converter — Converts JSON to XML or XML to JSON, with automatic format detection and configurable indentation.
  • SQL Formatter — Beautifies SQL queries with proper indentation and keyword casing, supporting multiple dialects (MySQL, PostgreSQL, SQL Server, BigQuery, and more).

Suggestions for new features or improvements are always welcome. The SQL Formatter uses the open-source sql-formatter library (MIT License), bundled locally so formatting still runs entirely in your browser.

About advertising and running this service

Formix may introduce advertising services such as Google AdSense in the future to help support running the site. If we do, how related data is handled will be explained transparently on the Privacy Policy page, and the core functionality of our tools (e.g. JSON processing) will remain free regardless of whether ads are shown.
