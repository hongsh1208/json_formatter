Preguntas frecuentes

Preguntas comunes sobre Formix, cómo maneja tus datos y cómo funcionan las herramientas.

¿Formix es gratis?

Sí. Todas las herramientas son completamente gratuitas y no se requiere registro ni cuenta. Podríamos mostrar anuncios en el futuro para ayudar a cubrir los costos de hospedaje, pero las herramientas en sí seguirán siendo gratuitas.

¿Mis datos se envían a un servidor?

No. Herramientas como el Formateador JSON y el Formateador XML procesan todo localmente en tu navegador usando JavaScript. El texto que pegas nunca se transmite ni se almacena en nuestros servidores. Consulta nuestra Política de privacidad para más detalles.

¿Necesito crear una cuenta?

No se necesita cuenta ni inicio de sesión para ninguna herramienta. Solo abre la página y empieza a usarla.

¿Qué navegadores son compatibles?

Cualquier navegador moderno (Chrome, Edge, Firefox, Safari) en escritorio o móvil funciona. Las herramientas dependen de APIs de JavaScript estándar y ampliamente compatibles como DOMParser y JSON.parse.

¿Puedo usar estas herramientas en mi teléfono?

Sí, el sitio es totalmente responsivo y funciona en navegadores móviles, aunque una pantalla más grande facilita trabajar con documentos JSON o XML largos.

¿Qué pasa si mi JSON o XML no es válido?

La herramienta muestra una insignia de estado y una línea/columna aproximada donde se encontró el problema, para que puedas localizarlo y corregirlo rápidamente. El Formateador JSON también puede autocorregir algunos errores comunes, como comillas faltantes.

¿Se añadirán más herramientas?

Sí. Formix comenzó con un Formateador JSON y ahora también ofrece un Formateador XML, un Convertidor JSON ↔ XML, un Formateador SQL y un Visor de código, además de dos juegos — una Prueba de velocidad de escritura y un Quiz de sintaxis de código. Planeamos seguir añadiendo pequeñas herramientas y juegos realmente útiles basados en el navegador — consulta nuestra página Acerca de para conocer los principios que nos guían.

¿Cómo reporto un error o sugiero una función?

Contáctanos a través de nuestra página de Contacto. Leemos cada mensaje.
