HERRAMIENTAS GRATUITAS EN LÍNEA

Herramientas en línea basadas en el navegador.
Sin instalación, sin registro.

Formix es una colección gratuita de utilidades en línea para las tareas pequeñas pero frecuentes del desarrollo y el trabajo diario. Todo lo que ingresas se procesa solo en tu propio equipo (en tu navegador) y nunca se envía a un servidor.

Herramientas disponibles

Prueba la herramienta a continuación ahora mismo — vienen más en camino.

🧩

Formateador / Visor JSON

Verifica si tu entrada es JSON válido y lo muestra como un árbol legible con resaltado de sintaxis. Incluye nodos colapsables y búsqueda de claves/valores.

JSON · Formateador · Validador
📄

Formateador / Visor XML

Verifica si tu entrada es XML válido y lo muestra como un árbol legible con resaltado de sintaxis. Incluye nodos colapsables y búsqueda de etiquetas/atributos/texto.

XML · Formateador · Validador
🔄

Convertidor JSON ↔ XML

Convierte JSON a XML o XML a JSON, con detección automática de formato. Incluye indicaciones de error por línea/columna y sangría configurable.

JSON · XML · Convertidor
🗄️

Formateador / Embellecedor SQL

Embellece consultas SQL con sangría adecuada y formato de palabras clave. Compatible con varios dialectos, incluidos MySQL, PostgreSQL, SQL Server y BigQuery.

SQL · Formateador · Embellecedor
🎨

Visor de código

Pega código fuente, elige un lenguaje (Java, C#, Python, Go y más de 15 adicionales) y míralo con resaltado de sintaxis para facilitar la lectura y el compartir.

Código · Resaltado de sintaxis · Visor
🔢

Lector de números

Convierte números en palabras — cardinales, ordinales, dígitos de teléfono/cuenta, hora, fecha y moneda, con varios estilos de lectura por idioma.

Números · Lector · Convertidor

Juegos

Juegos cortos, solo en el navegador, para un descanso rápido — sin registro, sin presión de tabla de clasificación (salvo la que decidas aceptar).

⌨️

Prueba de velocidad de escritura

Mide tu velocidad de escritura (PPM) y precisión con pasajes cortos de práctica, y comparte tu puntuación. Todo el cálculo se hace localmente en tu navegador.

Escritura · PPM · Juego
🧠

Quiz de sintaxis de código

Un quiz de opción múltiple sobre la sintaxis básica de JavaScript, Python, Java y C. Elige un lenguaje y descubre cuántas aciertas.

Quiz · Sintaxis · Juego

¿Por qué Formix?

  • Sin instalación ni registro — Solo abre el enlace y empieza a usarlo de inmediato.
  • Procesado en tu navegador — Tu entrada se maneja completamente del lado del cliente y nunca se envía a un servidor.
  • Soporte para modo oscuro — Cambia entre temas claro y oscuro en cualquier momento con el botón de la parte superior derecha.
  • Expansión continua — Planeamos seguir añadiendo herramientas útiles para el desarrollo y el trabajo diario.
