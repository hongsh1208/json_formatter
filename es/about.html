Acerca de

Una introducción a qué es Formix y los principios por los que se rige.

¿Qué es Formix?

Formix es una colección gratuita de utilidades en línea que te permite manejar tareas pequeñas pero tediosas que suelen surgir durante el desarrollo o el trabajo, directamente en tu navegador web — sin instalar ningún programa aparte, sin necesidad de registro. La primera herramienta que ofrecemos es el Formateador JSON, y planeamos seguir añadiendo herramientas realmente útiles para el trabajo diario.

Nuestros principios

  • Úsalo al instante, sin registro — Cualquiera puede empezar a usarlo de inmediato — no se necesita cuenta ni inicio de sesión.
  • Procesamiento del lado del cliente — La mayoría de las herramientas procesan tu entrada completamente en el navegador (JavaScript) y nunca la envían a un servidor. Consulta nuestra Política de privacidad para más detalles.
  • Ligero y rápido — Buscamos una pantalla simple que elimine elementos innecesarios y se enfoque en las funciones que realmente necesitas.
  • Modo oscuro incorporado — Elige entre temas claro y oscuro, automáticamente según la configuración de tu sistema o manualmente con el interruptor.

Funciones disponibles

  • Formateador / Visor JSON — Valida cadenas JSON y las muestra como un árbol con sangría y resaltado de sintaxis. Permite colapsar/expandir nodos y buscar claves y valores.
  • Formateador / Visor XML — Valida cadenas XML y las muestra como un árbol con sangría y resaltado de sintaxis. Permite colapsar/expandir nodos y buscar etiquetas, atributos y texto.
  • Convertidor JSON ↔ XML — Convierte JSON a XML o XML a JSON, con detección automática de formato y sangría configurable.
  • Formateador SQL — Embellece consultas SQL con sangría adecuada y formato de palabras clave, compatible con varios dialectos (MySQL, PostgreSQL, SQL Server, BigQuery y más).
  • Visor de código — Pega código fuente y elige un lenguaje para verlo con resaltado de sintaxis, compatible con más de 20 lenguajes, incluidos Java, C#, Python y Go.
  • Lector de números — Convierte números en palabras para cardinales, ordinales, dígitos de teléfono/cuenta, hora, fecha y moneda, con varios estilos de lectura por idioma.
  • Prueba de velocidad de escritura — Mide tu velocidad de escritura (PPM) y precisión en pasajes cortos de práctica y te permite compartir tu puntuación. El cálculo ocurre completamente en tu navegador.
  • Quiz de sintaxis de código — Un quiz de opción múltiple sobre la sintaxis básica de JavaScript, Python, Java y C.

Las sugerencias de nuevas funciones o mejoras siempre son bienvenidas. El Formateador SQL usa la biblioteca de código abierto sql-formatter (licencia MIT), y el Visor de código usa Prism.js (licencia MIT), ambas incluidas localmente para que el procesamiento siga ocurriendo enteramente en tu navegador. El Lector de números y la Prueba de velocidad de escritura están implementados con código propio y no usan ninguna biblioteca externa.

Sobre la publicidad y el funcionamiento de este servicio

Formix podría introducir servicios publicitarios como Google AdSense en el futuro para ayudar a sostener el sitio. Si lo hacemos, cómo se manejan los datos relacionados se explicará de forma transparente en la página de Política de privacidad, y la funcionalidad principal de nuestras herramientas (p. ej. el procesamiento de JSON) seguirá siendo gratuita independientemente de si se muestran anuncios.
