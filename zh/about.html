关于本站

介绍Formix是一项怎样的服务，以及它的运营理念。

什么是Formix?

Formix是一套免费的在线实用工具集，让你无需安装额外程序、无需注册账号，就能在网页浏览器中直接处理开发或工作中常见的琐碎任务。首个提供的功能是JSON 格式化工具，未来还会持续添加对实际工作有帮助的工具。

运营理念

  • 无需注册，立即使用 — 任何人无需账号或登录即可立即使用。
  • 客户端处理 — 大多数工具不会将输入内容发送到服务器，仅在浏览器(JavaScript)中处理。详情请参阅隐私政策。
  • 轻量快速的界面 — 减少不必要的元素，专注于真正需要的功能，力求界面简洁。
  • 默认支持深色模式 — 可根据系统设置自动切换，或手动在浅色/深色主题之间切换。

已提供的功能

  • JSON 格式化 / 查看器 — 验证 JSON 字符串的有效性，并以带缩进和语法高亮的树形结构展示。支持节点折叠/展开以及键值搜索。
  • XML 格式化 / 查看器 — 验证 XML 字符串的有效性，并以带缩进和语法高亮的树形结构展示。支持节点折叠/展开以及标签·属性·文本搜索。
  • JSON ↔ XML 转换工具 — 将 JSON 转换为 XML，或将 XML 转换为 JSON，支持自动检测格式与自定义缩进。
  • SQL 格式化工具 — 为 SQL 查询语句添加清晰的缩进和关键字大小写格式化，支持 MySQL、PostgreSQL、SQL Server、BigQuery 等多种方言。
  • 代码查看器 — 粘贴源代码并选择语言，即可获得带语法高亮的展示，支持 Java、C#、Python、Go 等 20 多种语言。
  • 数字读法转换 — 将数字转换为基数、序数、电话/账号、时间、日期、货币等读法。每种语言均支持多种表示方式。
  • 打字速度测试 — 通过简短的练习句子测量打字速度(WPM)和准确率，并可分享成绩。所有计分均在浏览器本地完成。
  • 编程语法测验 — 一个关于 JavaScript、Python、Java 和 C 基础语法的选择题测验。

欢迎随时提出新功能建议或改进意见。SQL 格式化工具使用了开源的 sql-formatter 库(MIT 许可)，代码查看器使用了 Prism.js(MIT 许可)，两者均已本地打包(vendor)，因此所有处理仍完全在您的浏览器中进行。数字读法转换和打字速度测试未使用任何外部库，均为我们自行实现。

关于广告与服务运营

为了维持服务运营，Formix未来可能会引入 Google AdSense 等广告服务。如果引入广告，相关数据的处理方式将在隐私政策页面中透明说明，工具的核心功能(如 JSON 处理)将始终免费提供，不受广告影响。
