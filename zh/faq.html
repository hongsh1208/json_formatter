常见问题

汇总了关于Formix的使用、数据处理方式以及工具用法的常见问题。

Formix是免费的吗?

是的，所有工具完全免费，无需注册或创建账号。为了补贴运营成本，未来可能会展示广告，但工具本身将始终保持免费。

我输入的数据会发送到服务器吗?

不会。JSON 格式化、XML 格式化等工具的所有处理都在您的浏览器中(通过 JavaScript)完成。您输入的文本不会被发送到服务器或被保存。详情请参阅隐私政策。

需要注册账号吗?

不需要。任何工具都无需账号或登录即可直接使用。

支持哪些浏览器?

电脑和手机上的主流最新浏览器(Chrome、Edge、Firefox、Safari)均可正常使用。工具使用的是 DOMParser、JSON.parse 等广泛支持的标准 JavaScript API。

可以在手机上使用吗?

可以，本站在移动浏览器上也能自适应正常显示。不过在处理较长的 JSON/XML 文档时，使用大屏幕设备会更方便。

如果我的 JSON 或 XML 无效会怎样?

工具会显示状态标记，并告知大致的错误行/列位置，方便您快速定位并修正问题。JSON 格式化工具还能自动修正部分常见错误，例如缺失的引号。

以后会添加更多工具吗?

会的。Formix从 JSON 格式化工具起步，目前也提供 XML 格式化工具、JSON ↔ XML 转换工具和 SQL 格式化工具。我们会持续添加对实际工作有帮助的浏览器端工具，运营理念请参阅关于本站页面。

如何反馈错误或提出功能建议?

请通过联系我们页面与我们联系，我们会查看每一条反馈。
