JSON ↔ XML 转换工具

在左侧粘贴 JSON 或 XML，右侧会显示转换为另一种格式的结果。Formix 会自动识别粘贴的格式，你也可以手动选择转换方向。数据不会发送到服务器。

提示：在"自动识别"模式下，Formix 会根据粘贴文本的第一个字符({或[表示JSON，<表示XML)自动判断转换方向；如果格式不明确，可以在下拉菜单中手动选择方向。由于 JSON 和 XML 表达数据的方式本质上不同，转换遵循固定规则：JSON 数组中重复的值会转换为多个同名的 XML 元素，XML 属性(attribute)会保留在结果 JSON 的 "@attributes" 对象中。因此，经过 JSON → XML → JSON 的往返转换后，原始结构可能无法完全还原(例如，顶层数组会被包裹在 结构中)。这是任何通用转换工具都会有的正常特性。

使用方法

  • 在左侧输入框粘贴 JSON 或 XML，格式会被自动识别，转换结果会显示在右侧。
  • 如果自动识别的格式不符合预期，可以在"转换方向"下拉菜单中手动选择 JSON → XML 或 XML → JSON。
  • 如果输入不是有效的 JSON/XML，会提示大致的出错行/列位置。
  • 使用缩进大小下拉菜单调整转换结果的排版方式，然后通过"复制"或"下载结果"获取。
  • "复制压缩结果"会复制去除所有不必要空白的转换结果，适合粘贴到配置文件或 API 请求中。
  • 所有处理均在浏览器内完成，输入的数据不会发送到服务器。

相关提示

  • JSON 对象的键会成为 XML 元素名称；包含空格或符号、无法作为 XML 标签名的键会被自动清理(sanitize)。
  • 由于 XML 没有原生的数组类型，像 ["a", "b"] 这样的 JSON 数组会转换为两个同名的兄弟元素，而不是一个包含列表的元素。
  • 转换带有属性的 XML(例如 )时，属性会被保留在结果 JSON 的 "@attributes" 键下，不会丢失信息。
  • 如果只需要单独校验或格式化 JSON 或 XML，请尝试下方相关链接中的 JSON 格式化工具或 XML 格式化工具。
