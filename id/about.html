Tentang

Pengantar tentang apa itu Formix dan prinsip yang mendasarinya.

Apa itu Formix?

Formix adalah kumpulan utilitas online gratis yang membantu Anda menangani tugas-tugas kecil namun merepotkan yang sering muncul saat pengembangan atau bekerja, langsung di browser web Anda — tanpa perlu menginstal program terpisah, tanpa perlu mendaftar. Alat pertama yang kami tawarkan adalah Pemformat JSON, dan kami berencana untuk terus menambahkan alat yang benar-benar bermanfaat untuk pekerjaan sehari-hari.

Prinsip kami

  • Gunakan langsung, tanpa pendaftaran — Siapa pun dapat langsung menggunakannya — tidak perlu akun atau login.
  • Pemrosesan di sisi klien — Sebagian besar alat memproses input Anda sepenuhnya di browser (JavaScript) dan tidak pernah mengirimkannya ke server. Lihat Kebijakan Privasi kami untuk detailnya.
  • Ringan dan cepat — Kami bertujuan menghadirkan tampilan sederhana yang menghilangkan elemen yang tidak perlu dan berfokus pada fitur yang benar-benar Anda butuhkan.
  • Mode gelap bawaan — Pilih antara tema terang dan gelap, baik secara otomatis dari pengaturan sistem Anda maupun secara manual dengan tombol pengalih.

Fitur yang tersedia

  • Pemformat / Penampil JSON — Memvalidasi string JSON dan menampilkannya sebagai pohon dengan indentasi dan penyorotan sintaks. Mendukung melipat/membuka node serta mencari kunci dan nilai.
  • Pemformat / Penampil XML — Memvalidasi string XML dan menampilkannya sebagai pohon dengan indentasi dan penyorotan sintaks. Mendukung melipat/membuka node serta mencari tag, atribut, dan teks.
  • Konverter JSON ↔ XML — Mengonversi JSON ke XML atau XML ke JSON, dengan deteksi format otomatis dan indentasi yang dapat disesuaikan.
  • Pemformat SQL — Merapikan kueri SQL dengan indentasi yang tepat dan penulisan kata kunci, mendukung berbagai dialek (MySQL, PostgreSQL, SQL Server, BigQuery, dan lainnya).
  • Penampil Kode — Tempel kode sumber dan pilih bahasa untuk melihatnya dengan penyorotan sintaks, mendukung lebih dari 20 bahasa termasuk Java, C#, Python, dan Go.
  • Pembaca Angka — Mengonversi angka menjadi kata untuk kardinal, ordinal, digit telepon/rekening, waktu, tanggal, dan mata uang, dengan beberapa gaya pembacaan per bahasa.
  • Tes Kecepatan Mengetik — Mengukur kecepatan mengetik (WPM) dan akurasi Anda pada paragraf latihan singkat dan memungkinkan Anda membagikan skor. Penilaian berjalan sepenuhnya di browser Anda.
  • Kuis Sintaks Koding — Kuis pilihan ganda tentang sintaks dasar JavaScript, Python, Java, dan C.

Saran untuk fitur baru atau perbaikan selalu kami sambut. Pemformat SQL menggunakan pustaka sumber terbuka sql-formatter (Lisensi MIT), dan Penampil Kode menggunakan Prism.js (Lisensi MIT), keduanya dibundel secara lokal sehingga pemrosesan tetap berjalan sepenuhnya di browser Anda. Pembaca Angka dan Tes Kecepatan Mengetik dibuat dengan kode kami sendiri tanpa pustaka eksternal.

Tentang iklan dan pengoperasian layanan ini

Formix mungkin memperkenalkan layanan iklan seperti Google AdSense di masa depan untuk membantu mendukung operasional situs. Jika demikian, cara penanganan data terkait akan dijelaskan secara transparan di halaman Kebijakan Privasi, dan fungsi inti alat kami (misalnya pemrosesan JSON) akan tetap gratis terlepas dari ditampilkannya iklan.
