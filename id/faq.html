Pertanyaan Umum

Pertanyaan umum tentang Formix, cara menangani data Anda, dan cara kerja alat-alatnya.

Apakah Formix gratis digunakan?

Ya. Semua alat sepenuhnya gratis, dan tidak perlu pendaftaran atau akun. Kami mungkin menampilkan iklan di masa depan untuk membantu menutupi biaya hosting, tetapi alat-alatnya sendiri akan tetap gratis.

Apakah data saya dikirim ke server?

Tidak. Alat seperti Pemformat JSON dan Pemformat XML memproses semuanya secara lokal di browser Anda menggunakan JavaScript. Teks yang Anda tempel tidak pernah ditransmisikan ke atau disimpan di server kami. Lihat Kebijakan Privasi kami untuk detailnya.

Apakah saya perlu membuat akun?

Tidak perlu akun atau login untuk alat apa pun. Cukup buka halamannya dan mulai gunakan.

Browser apa yang didukung?

Browser modern apa pun (Chrome, Edge, Firefox, Safari) di desktop atau seluler berfungsi dengan baik. Alat-alat ini mengandalkan API JavaScript standar yang didukung secara luas seperti DOMParser dan JSON.parse.

Bisakah saya menggunakan alat ini di ponsel saya?

Ya, situs ini sepenuhnya responsif dan berfungsi di browser seluler, meskipun layar yang lebih besar memudahkan pengerjaan dokumen JSON atau XML yang panjang.

Apa yang terjadi jika JSON atau XML saya tidak valid?

Alat akan menampilkan lencana status dan perkiraan baris/kolom tempat masalah ditemukan, sehingga Anda dapat dengan cepat menemukan dan memperbaiki masalah tersebut. Pemformat JSON juga dapat secara otomatis memperbaiki beberapa kesalahan umum, seperti tanda kutip yang hilang.

Apakah akan ada lebih banyak alat yang ditambahkan?

Ya. Formix dimulai dengan Pemformat JSON dan sekarang juga menawarkan Pemformat XML, Konverter JSON ↔ XML, Pemformat SQL, dan Penampil Kode, ditambah dua permainan — Tes Kecepatan Mengetik dan Kuis Sintaks Koding. Kami berencana untuk terus menambahkan alat dan permainan kecil berbasis browser yang benar-benar bermanfaat — lihat halaman Tentang kami untuk prinsip yang memandu kami.

Bagaimana cara melaporkan bug atau menyarankan fitur?

Silakan hubungi kami melalui halaman Kontak. Kami membaca setiap pesan.
