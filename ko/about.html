사이트 소개

Formix가 어떤 서비스인지, 어떤 원칙으로 운영되는지 소개합니다.

Formix란?

Formix는 개발이나 업무 중 자주 마주하지만 번거로운 작업을 별도 프로그램 설치나 회원가입 없이, 웹 브라우저에서 바로 처리할 수 있도록 만든 무료 온라인 유틸리티 모음입니다. 첫 번째로 제공하는 기능은 JSON 포매터이며, 앞으로도 실무에 도움이 되는 도구를 지속적으로 추가할 예정입니다.

운영 원칙

  • 가입 없이 바로 사용 — 별도의 계정이나 로그인 없이 누구나 즉시 이용할 수 있습니다.
  • 클라이언트 사이드 처리 — 대부분의 도구는 입력값을 서버로 전송하지 않고 브라우저(자바스크립트) 안에서만 처리합니다. 자세한 내용은 개인정보처리방침을 참고해주세요.
  • 가벼고 빠른 화면 — 불필요한 요소를 줄이고 필요한 기능에 집중한 단순한 화면을 지향합니다.
  • 다크 모드 기본 지원 — 시스템 설정 또는 수동 전환으로 라이트/다크 테마를 선택할 수 있습니다.

제공 중인 기능

  • JSON 포매터 / 뷰어 — JSON 문자열의 유효성을 검사하고, 들여쓰기·문법 강조가 적용된 트리 형태로 보여줍니다. 노드 접기/펼치기와 키·값 검색을 지원합니다.
  • XML 포매터 / 뷰어 — XML 문자열의 유효성을 검사하고, 들여쓰기·문법 강조가 적용된 트리 형태로 보여줍니다. 노드 접기/펼치기와 태그·속성·텍스트 검색을 지원합니다.
  • JSON ↔ XML 변환기 — JSON을 XML로, XML을 JSON으로 변환합니다. 형식 자동 감지와 들여쓰기 설정을 지원합니다.
  • SQL 포매터 — SQL 쿼리를 알아보기 쉽게 들여쓰기하고 키워드 대소문자를 정리합니다. MySQL, PostgreSQL, SQL Server, BigQuery 등 여러 방언을 지원합니다.
  • 코드 뷰어 — 소스 코드를 붙여넣고 언어를 선택하면 문법 강조가 적용된 화면으로 보여줍니다. Java, C#, Python, Go 등 20여 개 언어를 지원합니다.
  • 숫자 읽기 변환기 — 숫자를 일반(기수), 서수, 전화·계좌번호, 시간, 날짜, 화폐 등으로 변환해 읽는 법을 보여줍니다. 언어별로 여러 표기 방식을 지원합니다.

새로운 기능 제안이나 개선 의견은 언제든 환영합니다. SQL 포매터는 오픈소스 sql-formatter 라이브러리(MIT 라이선스)를, 코드 뷰어는 Prism.js(MIT 라이선스)를 사용하며, 둘 다 로컬에 내장(vendor)하여 여전히 모든 처리가 브라우저 안에서만 이뤄집니다. 숫자 읽기 변환기는 외부 라이브러리 없이 자체 구현했습니다.

광고 및 서비스 운영에 대해

Formix는 서비스 운영을 위해 향후 Google AdSense 등 광고 서비스를 도입할 수 있습니다. 광고 도입 시 관련 데이터 처리 방식은 개인정보처리방침 페이지를 통해 투명하게 안내하며, 도구의 핵심 기능(예: JSON 처리)은 광고 여부와 무관하게 계속 무료로 제공됩니다.
