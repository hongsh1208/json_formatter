JSON ↔ XML 변환기

왼쪽에 JSON 또는 XML을 붙여넣으면 오른쪽에 반대 형식으로 변환된 결과가 표시됩니다. 어떤 형식을 붙여넣었는지는 Formix가 자동으로 감지하며, 방향을 직접 선택할 수도 있습니다. 데이터는 서버로 전송되지 않습니다.

Tip. "자동 감지" 모드에서는 붙여넣은 텍스트의 첫 글자({ 또는 [ 는 JSON, < 는 XML)로 방향을 자동으로 판단합니다. 형식이 애매하면 드롭다운에서 방향을 직접 선택해주세요. JSON과 XML은 데이터를 표현하는 방식이 근본적으로 다르기 때문에, 변환은 정해진 규칙을 따릅니다: JSON 배열의 반복되는 값은 같은 태그명을 가진 XML 엘리먼트 여러 개로 변환되고, XML 속성(attribute)은 JSON에서 "@attributes" 객체로 보존됩니다. 이 때문에 JSON → XML → JSON으로 왕복 변환하면 원래 모양이 완전히 똑같이 복원되지 않을 수 있습니다(예: 최상위 배열은 구조로 감싸짐). 이는 범용 변환기라면 자연스럽게 발생하는 특성입니다.

이 도구는 이렇게 사용하세요

  • 왼쪽 입력창에 JSON 또는 XML을 붙여넣으면 형식이 자동으로 감지되어 오른쪽에 변환 결과가 표시됩니다.
  • 자동 감지가 원하는 형식과 다르게 판단했다면 "변환 방향" 드롭다운에서 JSON → XML 또는 XML → JSON을 직접 선택하세요.
  • 입력이 유효한 JSON/XML이 아니면 오류가 발생한 대략적인 줄/열 위치를 알려줍니다.
  • 들여쓰기 크기 드롭다운으로 변환 결과의 정렬 방식을 조절한 뒤, "복사" 또는 "결과 다운로드"로 가져갈 수 있습니다.
  • "압축 복사"는 불필요한 공백을 모두 제거한 변환 결과를 복사합니다. 설정 파일이나 API 요청에 붙여넣을 때 유용합니다.
  • 모든 처리는 브라우저 안에서만 이뤄지며, 입력한 데이터는 서버로 전송되지 않습니다.

관련 팁

  • JSON 객체의 키는 XML 엘리먼트 이름이 됩니다. 공백이나 기호가 포함되어 XML 태그명으로 쓸 수 없는 키는 자동으로 정리(sanitize)됩니다.
  • XML에는 배열 타입이 없기 때문에, ["a", "b"] 같은 JSON 배열은 하나의 엘리먼트가 아니라 같은 태그명을 가진 형제 엘리먼트 두 개로 변환됩니다.
  • 속성이 있는 XML(예: )을 변환하면, 정보 손실 없이 결과 JSON의 "@attributes" 키 아래에 담깁니다.
