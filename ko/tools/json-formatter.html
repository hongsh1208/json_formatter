JSON 포매터 / 뷰어

JSON 문자열을 입력하면 유효성을 검사하고, 들여쓰기와 문법 강조가 적용된 트리로 정리해 보여줍니다. 입력값은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

JSON을 입력해주세요
결과
0 / 0

Tip. 입력을 멈추면 유효성을 검사해 정상이면 자동으로 "결과" 탭으로 전환합니다. 결과 탭의 점은 현재 유효성 상태를 보여줍니다. 객체/배열을 접거나 펼치는 ▾/▸ 버튼은 줄 번호 옆(왼쪽 여백)에 있어 클릭하기 편합니다. 검색창은 결과 탭이 열리면 자동으로 포커스되며, 검색 방식(포함/일치/정규식)을 선택해 원하는 방식으로 키와 값을 찾을 수 있습니다. 결과 화면 왼쪽의 줄 번호는 접기/펼치기 상태에 맞춰 보이는 줄만 다시 매겨져, 구조가 접혀 있어도 위치를 가늠하기 쉽습니다. 입력창에도 동일한 방식의 검색(포함/일치/정규식)이 있어 원본 텍스트에서 바로 위치를 찾고 강조 표시로 확인할 수 있습니다. Enter(다음) / Shift+Enter(이전)로 일치 항목을 이동할 수 있습니다. 키나 문자열 값의 큰따옴표(")가 일부 빠져 있어도 가능한 한 JSON으로 인식해서 보여줍니다.

이 도구는 이렇게 사용하세요

  • 왼쪽 입력창에 JSON 문자열을 붙여넣으면 자동으로 유효성을 검사하고 결과를 그려줍니다.
  • 유효하지 않은 JSON이면 오류가 발생한 대략적인 줄/열 위치를 함께 알려줍니다.
  • "정렬(Format)" 버튼을 누르면 입력창의 내용도 선택한 들여쓰기 기준으로 정리됩니다.
  • 결과가 길 때는 "모두 접기"로 전체 구조를 먼저 훑어본 뒤, 줄 번호 옆의 ▾/▸ 버튼으로 필요한 노드만 펼쳐볼 수 있습니다.
  • 모든 처리는 브라우저 안에서만 이뤄지며, 입력한 데이터는 서버로 전송되지 않습니다.
  • 키나 문자열 값의 큰따옴표가 일부 누락된 경우에도 최대한 자동으로 보정해서 인식합니다. 이 경우 상태 배지에 "보정됨"으로 표시되고, 입력창 왼쪽 줄 번호 중 보정이 일어난 줄이 강조 표시됩니다.
  • 입력을 마치고 결과가 정상(유효 또는 보정됨)으로 확인되면 자동으로 "결과" 탭으로 전환되고, 검색창에 바로 입력할 수 있도록 포커스가 이동합니다.
  • 검색 방식을 "포함"(부분 일치), "일치"(정확히 같은 값), "정규식"(정규 표현식) 중에서 선택할 수 있습니다.
  • 입력창 상단에도 같은 검색 기능(포함/일치/정규식, 이전·다음 이동, 강조 표시)이 있어 원본 텍스트에서 바로 찾을 수 있습니다.
