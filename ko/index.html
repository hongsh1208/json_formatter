브라우저 기반 온라인 도구 모음

Formix는 개발과 업무 중 자주 필요한 자잔한 작업들을 브라우저에서 바로 끝낼 수 있게 만든 무료 온라인 유틸리티 모음입니다. 입력한 데이터는 서버로 전송되지 않고 내 컴퓨터(브라우저) 안에서만 처리되어 안전하게 사용할 수 있습니다.

제공 기능

아래 기능을 바로 사용해보세요. 새로운 도구는 계속 추가될 예정입니다.

🧩

JSON 포매터 / 뷰어

입력한 문자열이 올바른 JSON인지 검사하고, 들여쓰기와 문법 강조를 적용해 가독성 좋게 보여줍니다. 트리 접기/펼치기와 키·값 검색 기능을 제공합니다.

JSON · Formatter · Validator
📄

XML 포매터 / 뷰어

입력한 문자열이 올바른 XML인지 검사하고, 들여쓰기와 문법 강조를 적용해 가독성 좋게 보여줍니다. 트리 접기/펼치기와 태그·속성·텍스트 검색 기능을 제공합니다.

XML · Formatter · Validator
🔄

JSON ↔ XML 변환기

JSON을 XML로, XML을 JSON으로 변환합니다. 형식을 자동으로 감지하며, 오류 줄/열 안내와 들여쓰기 설정을 지원합니다.

JSON · XML · Converter
🗄️

SQL 포매터 / 정렬기

SQL 쿼리를 알아보기 쉽게 들여쓰기하고 키워드 대소문자를 정리합니다. MySQL, PostgreSQL, SQL Server, BigQuery 등 여러 방언을 지원합니다.

SQL · Formatter · Beautifier
🎨

코드 뷰어

소스 코드를 붙여넣고 언어(Java, C#, Python, Go 등 20여 개)를 선택하면 문법 강조가 적용된 화면으로 보기 좋게 표시합니다.

Code · Syntax Highlighting · Viewer
🔢

숫자 읽기 변환기

숫자를 문자로 변환합니다. 일반(기수), 서수, 전화·계좌번호, 시간, 날짜, 화폐 모드를 지원하며 언어별로 여러 표기 방식(예: 한자어/고유어/갖은자)을 제공합니다.

숫자 · 읽기 · 변환기
