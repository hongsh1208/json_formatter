자주 묻는 질문

Formix 이용, 데이터 처리 방식, 도구 사용법에 대해 자주 묻는 질문들을 모았습니다.

Formix는 무료인가요?

네, 모든 도구는 완전히 무료이며 회원가입이나 계정 생성이 필요하지 않습니다. 운영비 충당을 위해 향후 광고를 게재할 수 있지만, 도구 자체는 계속 무료로 제공됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. JSON 포매터, XML 포매터 등의 도구는 모든 처리를 브라우저 안에서(자바스크립트로) 수행합니다. 입력한 텍스트는 서버로 전송되거나 저장되지 않습니다. 자세한 내용은 개인정보처리방침을 참고해주세요.

회원가입이 필요한가요?

필요하지 않습니다. 어떤 도구든 계정이나 로그인 없이 바로 사용할 수 있습니다.

어떤 브라우저를 지원하나요?

PC와 모바일의 최신 브라우저(Chrome, Edge, Firefox, Safari)에서 모두 사용할 수 있습니다. DOMParser, JSON.parse 등 널리 지원되는 표준 자바스크립트 API를 사용합니다.

모바일에서도 사용할 수 있나요?

네, 모바일 브라우저에서도 반응형으로 정상 동작합니다. 다만 긴 JSON·XML 문서를 다룰 때는 화면이 큰 기기가 더 편리합니다.

JSON이나 XML이 유효하지 않으면 어떻게 되나요?

상태 배지와 함께 문제가 발생한 대략적인 줄/열 위치를 알려줘 빠르게 확인하고 수정할 수 있습니다. JSON 포매터는 따옴표 누락 같은 흔한 실수를 자동으로 보정하기도 합니다.

앞으로 도구가 더 추가되나요?

네. Formix는 JSON 포매터로 시작해 현재는 XML 포매터, JSON ↔ XML 변환기, SQL 포매터, 코드 뷰어, 숫자 읽기 변환기도 제공하고 있습니다. 앞으로도 실무에 유용한 브라우저 기반 도구를 계속 추가할 예정입니다. 운영 철학은 사이트 소개 페이지를 참고해주세요.

버그 제보나 기능 제안은 어떻게 하나요?

문의하기 페이지를 통해 연락해주세요. 보내주시는 의견은 모두 확인하고 있습니다.
