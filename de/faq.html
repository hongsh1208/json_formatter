Häufige Fragen

Häufige Fragen zu Formix, wie es mit Ihren Daten umgeht und wie die Tools funktionieren.

Ist Formix kostenlos nutzbar?

Ja. Alle Tools sind völlig kostenlos, und es ist keine Registrierung oder Konto erforderlich. Wir zeigen möglicherweise in Zukunft Werbung an, um Hosting-Kosten zu decken, aber die Tools selbst bleiben kostenlos.

Werden meine Daten an einen Server gesendet?

Nein. Tools wie der JSON-Formatierer und der XML-Formatierer verarbeiten alles lokal in Ihrem Browser mit JavaScript. Der Text, den Sie einfügen, wird niemals an unsere Server übermittelt oder dort gespeichert. Details finden Sie in unserer Datenschutzerklärung.

Muss ich ein Konto erstellen?

Für kein Tool ist ein Konto oder eine Anmeldung erforderlich. Öffnen Sie einfach die Seite und nutzen Sie es sofort.

Welche Browser werden unterstützt?

Jeder moderne Browser (Chrome, Edge, Firefox, Safari) auf Desktop oder Mobilgerät funktioniert. Die Tools basieren auf weit verbreiteten Standard-JavaScript-APIs wie DOMParser und JSON.parse.

Kann ich diese Tools auf meinem Smartphone nutzen?

Ja, die Website ist vollständig responsiv und funktioniert in mobilen Browsern, wobei ein größerer Bildschirm die Arbeit mit langen JSON- oder XML-Dokumenten erleichtert.

Was passiert, wenn mein JSON oder XML ungültig ist?

Das Tool zeigt ein Statusabzeichen und eine ungefähre Zeile/Spalte an, an der das Problem gefunden wurde, damit Sie es schnell lokalisieren und beheben können. Der JSON-Formatierer kann auch einige häufige Fehler automatisch korrigieren, wie fehlende Anführungszeichen.

Werden weitere Tools hinzugefügt?

Ja. Formix begann mit einem JSON-Formatierer und bietet jetzt auch einen XML-Formatierer, einen JSON ↔ XML Konverter, einen SQL-Formatierer und einen Code-Viewer, sowie zwei Spiele — einen Schreibgeschwindigkeitstest und ein Coding-Syntax-Quiz. Wir planen, weiterhin kleine, wirklich nützliche browserbasierte Tools und Spiele hinzuzufügen — die Prinzipien, die uns leiten, finden Sie auf unserer Seite Über uns.

Wie melde ich einen Fehler oder schlage eine Funktion vor?

Bitte kontaktieren Sie uns über unsere Kontaktseite. Wir lesen jede Nachricht.
