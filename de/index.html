KOSTENLOSE ONLINE-TOOLS

Browserbasierte Online-Tools.
Keine Installation, keine Registrierung.

Formix ist eine kostenlose Sammlung von Online-Dienstprogrammen für die kleinen, alltäglichen Aufgaben in Entwicklung und Arbeit. Alles, was Sie eingeben, wird nur auf Ihrem eigenen Computer (im Browser) verarbeitet und nie an einen Server gesendet.

Verfügbare Tools

Probieren Sie das Tool unten direkt aus — weitere Tools sind in Arbeit.

🧩

JSON-Formatierer / Viewer

Prüft, ob Ihre Eingabe gültiges JSON ist, und zeigt es als lesbaren, syntaxhervorgehobenen Baum an. Mit einklappbaren Knoten und Schlüssel-/Wert-Suche.

JSON · Formatierer · Validator
📄

XML-Formatierer / Viewer

Prüft, ob Ihre Eingabe gültiges XML ist, und zeigt es als lesbaren, syntaxhervorgehobenen Baum an. Mit einklappbaren Knoten und Tag-/Attribut-/Text-Suche.

XML · Formatierer · Validator
🔄

JSON ↔ XML Konverter

Konvertiert JSON in XML oder XML in JSON, mit automatischer Formaterkennung. Mit Fehlerhinweisen zu Zeile/Spalte und konfigurierbarer Einrückung.

JSON · XML · Konverter
🗄️

SQL-Formatierer / Beautifier

Formatiert SQL-Abfragen mit korrekter Einrückung und Schlüsselwort-Schreibweise. Unterstützt mehrere Dialekte, darunter MySQL, PostgreSQL, SQL Server und BigQuery.

SQL · Formatierer · Beautifier
🎨

Code-Viewer

Quellcode einfügen, eine Sprache wählen (Java, C#, Python, Go und 15+ weitere) und mit Syntaxhervorhebung zum leichteren Lesen und Teilen anzeigen.

Code · Syntaxhervorhebung · Viewer
🔢

Zahlen-Vorleser

Wandelt Zahlen in Wörter um — Grund- und Ordnungszahlen, Telefon-/Kontoziffern, Uhrzeit, Datum und Währung, mit mehreren Lesestilen je Sprache.

Zahlen · Vorleser · Konverter

Spiele

Kurze, reine Browser-Spiele für eine schnelle Pause — keine Registrierung, kein Ranglisten-Druck (außer dem, dem Sie selbst beitreten möchten).

⌨️

Schreibgeschwindigkeitstest

Messen Sie Ihre Schreibgeschwindigkeit (WPM) und Genauigkeit mit kurzen Übungstexten und teilen Sie Ihr Ergebnis. Die gesamte Auswertung erfolgt lokal in Ihrem Browser.

Tippen · WPM · Spiel
🧠

Coding-Syntax-Quiz

Ein Multiple-Choice-Quiz zur Grundsyntax von JavaScript, Python, Java und C. Wählen Sie eine Sprache und sehen Sie, wie viele Sie richtig beantworten.

Quiz · Syntax · Spiel

Warum Formix?

  • Keine Installation oder Registrierung — Einfach den Link öffnen und sofort losnutzen.
  • Im Browser verarbeitet — Ihre Eingabe wird vollständig clientseitig verarbeitet und nie an einen Server gesendet.
  • Dunkelmodus-Unterstützung — Jederzeit mit dem Schalter oben rechts zwischen Hell- und Dunkelmodus wechseln.
  • Stetig wachsend — Wir planen, weiterhin nützliche Tools für Entwicklung und Alltag hinzuzufügen.
