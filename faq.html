Frequently Asked Questions

Common questions about Formix, how it handles your data, and how the tools work.

Is Formix free to use?

Yes. All tools are completely free, and there is no sign-up or account required. We may show ads in the future to help cover hosting costs, but the tools themselves will remain free.

Is my data sent to a server?

No. Tools like the JSON Formatter and XML Formatter process everything locally in your browser using JavaScript. The text you paste in is never transmitted to or stored on our servers. See our Privacy Policy for details.

Do I need to create an account?

No account or login is required for any tool. Just open the page and start using it.

Which browsers are supported?

Any modern browser (Chrome, Edge, Firefox, Safari) on desktop or mobile works. The tools rely on standard, widely-supported JavaScript APIs like DOMParser and JSON.parse.

Can I use these tools on my phone?

Yes, the site is fully responsive and works on mobile browsers, though a larger screen makes it easier to work with long JSON or XML documents.

What happens if my JSON or XML is invalid?

The tool shows a status badge and an approximate line/column where the problem was found, so you can locate and fix the issue quickly. The JSON Formatter can also auto-correct some common mistakes, like missing quotes.

Will more tools be added?

Yes. Formix started with a JSON Formatter and now also offers an XML Formatter, a JSON ↔ XML Converter, a SQL Formatter, a Code Viewer, and a Number Reader. We plan to keep adding small, genuinely useful browser-based tools over time — see our About page for our guiding principles.

How do I report a bug or suggest a feature?

Please reach out through our Contact page. We read every message.
