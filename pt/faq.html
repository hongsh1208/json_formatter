Perguntas frequentes

Perguntas comuns sobre o Formix, como ele trata seus dados e como as ferramentas funcionam.

O Formix é gratuito?

Sim. Todas as ferramentas são completamente gratuitas e não é necessário cadastro ou conta. Podemos exibir anúncios no futuro para ajudar a cobrir custos de hospedagem, mas as próprias ferramentas permanecerão gratuitas.

Meus dados são enviados a um servidor?

Não. Ferramentas como o Formatador JSON e o Formatador XML processam tudo localmente no seu navegador usando JavaScript. O texto que você cola nunca é transmitido ou armazenado em nossos servidores. Veja nossa Política de privacidade para detalhes.

Preciso criar uma conta?

Nenhuma conta ou login é necessário para nenhuma ferramenta. Basta abrir a página e começar a usar.

Quais navegadores são compatíveis?

Qualquer navegador moderno (Chrome, Edge, Firefox, Safari) em desktop ou celular funciona. As ferramentas dependem de APIs JavaScript padrão e amplamente suportadas, como DOMParser e JSON.parse.

Posso usar essas ferramentas no celular?

Sim, o site é totalmente responsivo e funciona em navegadores móveis, embora uma tela maior facilite o trabalho com documentos JSON ou XML longos.

O que acontece se meu JSON ou XML for inválido?

A ferramenta exibe um indicador de status e uma linha/coluna aproximada de onde o problema foi encontrado, para que você possa localizá-lo e corrigi-lo rapidamente. O Formatador JSON também pode corrigir automaticamente alguns erros comuns, como aspas faltantes.

Mais ferramentas serão adicionadas?

Sim. O Formix começou com um Formatador JSON e agora também oferece um Formatador XML, um Conversor JSON ↔ XML, um Formatador SQL e um Visualizador de código, além de dois jogos — um Teste de velocidade de digitação e um Quiz de sintaxe de código. Planejamos continuar adicionando ferramentas e jogos pequenos e realmente úteis baseados no navegador — veja nossa página Sobre para os princípios que nos guiam.

Como relato um erro ou sugiro uma funcionalidade?

Entre em contato pela nossa página de Contato. Lemos todas as mensagens.
