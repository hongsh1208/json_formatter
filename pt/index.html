FERRAMENTAS ONLINE GRATUITAS

Ferramentas online baseadas no navegador.
Sem instalação, sem cadastro.

O Formix é uma coleção gratuita de utilitários online para as pequenas tarefas do dia a dia no desenvolvimento e no trabalho. Tudo o que você digita é processado apenas no seu próprio computador (no navegador) e nunca é enviado a um servidor.

Ferramentas disponíveis

Experimente a ferramenta abaixo agora mesmo — mais ferramentas estão a caminho.

🧩

Formatador / Visualizador JSON

Verifica se sua entrada é um JSON válido e a exibe como uma árvore legível com destaque de sintaxe. Inclui nós recolhíveis e busca de chave/valor.

JSON · Formatador · Validador
📄

Formatador / Visualizador XML

Verifica se sua entrada é um XML válido e a exibe como uma árvore legível com destaque de sintaxe. Inclui nós recolhíveis e busca de tag/atributo/texto.

XML · Formatador · Validador
🔄

Conversor JSON ↔ XML

Converte JSON para XML ou XML para JSON, com detecção automática de formato. Inclui dicas de erro por linha/coluna e recuo configurável.

JSON · XML · Conversor
🗄️

Formatador / Embelezador SQL

Embeleza consultas SQL com recuo adequado e formatação de palavras-chave. Compatível com vários dialetos, incluindo MySQL, PostgreSQL, SQL Server e BigQuery.

SQL · Formatador · Embelezador
🎨

Visualizador de código

Cole o código-fonte, escolha uma linguagem (Java, C#, Python, Go e mais de 15 outras) e veja com destaque de sintaxe para facilitar a leitura e o compartilhamento.

Código · Destaque de sintaxe · Visualizador
🔢

Leitor de números

Converte números em palavras — cardinais, ordinais, dígitos de telefone/conta, hora, data e moeda, com vários estilos de leitura por idioma.

Números · Leitor · Conversor

Jogos

Jogos curtos, só no navegador, para uma pausa rápida — sem cadastro, sem pressão de ranking (exceto o que você escolher participar).

⌨️

Teste de velocidade de digitação

Meça sua velocidade de digitação (PPM) e precisão com trechos curtos de prática, depois compartilhe sua pontuação. Toda a pontuação é calculada localmente no seu navegador.

Digitação · PPM · Jogo
🧠

Quiz de sintaxe de código

Um quiz de múltipla escolha sobre a sintaxe básica de JavaScript, Python, Java e C. Escolha uma linguagem e veja quantas você acerta.

Quiz · Sintaxe · Jogo

Por que o Formix?

  • Sem instalação nem cadastro — Basta abrir o link e começar a usar imediatamente.
  • Processado no seu navegador — Sua entrada é tratada inteiramente no lado do cliente e nunca é enviada a um servidor.
  • Suporte a modo escuro — Alterne entre os temas claro e escuro a qualquer momento pelo botão no canto superior direito.
  • Expansão contínua — Planejamos continuar adicionando ferramentas úteis para o trabalho e o desenvolvimento do dia a dia.
