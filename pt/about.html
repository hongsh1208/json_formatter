Sobre

Uma introdução ao que é o Formix e aos princípios que o guiam.

O que é o Formix?

O Formix é uma coleção gratuita de utilitários online que permite lidar com pequenas tarefas, mas tediosas, comuns no desenvolvimento ou no trabalho, diretamente no seu navegador — sem instalar nenhum programa separado, sem necessidade de cadastro. A primeira ferramenta que oferecemos é o Formatador JSON, e planejamos continuar adicionando ferramentas realmente úteis para o dia a dia.

Nossos princípios

  • Use instantaneamente, sem cadastro — Qualquer pessoa pode começar a usar imediatamente — nenhuma conta ou login é necessário.
  • Processamento no lado do cliente — A maioria das ferramentas processa sua entrada inteiramente no navegador (JavaScript) e nunca a envia a um servidor. Veja nossa Política de privacidade para detalhes.
  • Leve e rápido — Buscamos uma tela simples que elimina elementos desnecessários e foca nas funcionalidades que você realmente precisa.
  • Modo escuro incluso — Escolha entre temas claro e escuro, automaticamente pelas configurações do sistema ou manualmente com o botão.

Funcionalidades disponíveis

  • Formatador / Visualizador JSON — Valida strings JSON e as exibe como uma árvore com recuo e destaque de sintaxe. Permite recolher/expandir nós e buscar chaves e valores.
  • Formatador / Visualizador XML — Valida strings XML e as exibe como uma árvore com recuo e destaque de sintaxe. Permite recolher/expandir nós e buscar tags, atributos e texto.
  • Conversor JSON ↔ XML — Converte JSON para XML ou XML para JSON, com detecção automática de formato e recuo configurável.
  • Formatador SQL — Embeleza consultas SQL com recuo adequado e formatação de palavras-chave, compatível com vários dialetos (MySQL, PostgreSQL, SQL Server, BigQuery e mais).
  • Visualizador de código — Cole o código-fonte e escolha uma linguagem para visualizá-lo com destaque de sintaxe, compatível com mais de 20 linguagens, incluindo Java, C#, Python e Go.
  • Leitor de números — Converte números em palavras para cardinais, ordinais, dígitos de telefone/conta, hora, data e moeda, com vários estilos de leitura por idioma.
  • Teste de velocidade de digitação — Mede sua velocidade de digitação (PPM) e precisão em trechos curtos de prática e permite compartilhar sua pontuação. O cálculo ocorre inteiramente no seu navegador.
  • Quiz de sintaxe de código — Um quiz de múltipla escolha sobre a sintaxe básica de JavaScript, Python, Java e C.

Sugestões de novas funcionalidades ou melhorias são sempre bem-vindas. O Formatador SQL usa a biblioteca de código aberto sql-formatter (licença MIT), e o Visualizador de código usa Prism.js (licença MIT), ambos empacotados localmente para que o processamento continue ocorrendo inteiramente no seu navegador. O Leitor de números e o Teste de velocidade de digitação foram implementados com código próprio, sem bibliotecas externas.

Sobre publicidade e a operação deste serviço

O Formix pode introduzir serviços de publicidade como o Google AdSense no futuro para ajudar a sustentar o site. Se o fizermos, a forma como os dados relacionados são tratados será explicada de forma transparente na página de Política de privacidade, e a funcionalidade principal de nossas ferramentas (como o processamento de JSON) permanecerá gratuita independentemente da exibição de anúncios.
